**Проект приюта для животных Animal Shelter.**

*Этот сайт для тех, кто хочет найти себе питомца.*
*Выбирай друга, оставь заявку на знакомство - и совсем скоро счастливых историй станет больше.*

## Стек технологий
* **Backend:** Python, Django (MVT, Class-Based Views, Django ORM)
* **База данных:** SQLite
* **Frontend:** HTML5, CSS3, Bootstrap 5
* **Инструменты:** Pillow (работа с изображениями), `python-dateutil`

## Ключевые инженерные решения
* **Архитектура на базе CBV (принцип DRY):** общая логика пагинации, фильтрации по виду животного и регистронезависимого поиска по кличке вынесена в базовый класс `BaseAnimalListView`, от которого унаследованы витрины «В приюте» и «Забрали домой».
* **Умная логика на уровне моделей:** реализован динамический расчёт возраста питомца от даты рождения (`relativedelta`) с правильным русским склонением числительных (год/года/лет, месяц/месяца/месяцев, день/дня/дней), а также автогенерация уникальных `slug` с разрешением коллизий.
* **Автоматизация обработки заявок:** при заполнении формы на знакомство с питомцем (`AdoptRequestCreateView`) данные сохраняются в БД и автоматически отправляются на email администратору приюта.
* **Кастомная админ-панель:** настроены фильтры по статусам и видам животных, поиск и удобное управление анкетами питомцев и входящими заявками.

## Запуск проекта:

1. Клонировать репозиторий и перейти в него в командной строке:
```
git clone git@github.com:AnnBogd/Animal_shelter.git
```
```
cd Animal_shelter
```

2. Создать и активировать виртуальное окружение (ОС Windows)
```
python -m venv venv
source venv/Scripts/activate
```

3. Установить зависимости:
```
pip install -r requirements.txt
```

4. Создать миграции
```
python manage.py makemigrations
```

5. Применить миграции
```
python manage.py migrate
```

6. Запуск проекта:
```
python manage.py runserver
```

После запуска сайт будет доступен по адресу `http://127.0.0`, а панель администратора — по адресу `http://127.0.0/admin/`.
